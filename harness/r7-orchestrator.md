# R7 — 오케스트레이터

상태: 사용자 기본값 승인 완료. 최종 지침 문서 형식은 AGENTS.md로 합의했으며, 초안의 저장 승인은 아직 받지 않았다.

## 자동 진행 범위

입력 확인 → 에이전트 순차 실행 → 판정 스크립트 실행 → 실패 단계 복귀를 자동 진행한다. 같은 게이트에서 수정 2회 후에도 실패하면 중단한다. 모든 자동 검사가 통과하면 최종 사람 승인 한 곳에서 기다린다.

## 준비물 확인

- 대상 기능·대상 화면 목록 5개가 없으면 질문한다.
- 경쟁 서비스가 지정되지 않으면 관련 서비스 3개를 조사해 선정한다.
- 원본 기준 문서 누락, Figma 접근 불가, 필수 실행 도구 부재는 차단 사유로 보고하고 해당 작업을 시작하지 않는다.

## 판정 도구 준비

최초 실행의 준비 단계에서 규칙에 맞는 판정 스크립트와 검증용 사례를 만들고 시험한다. 이후 작업 에이전트는 판정 스크립트를 수정할 수 없다.

판정 변경이 필요하면 실행을 멈추고 변경 이유를 보고한다. 스크립트 오류·증거 누락은 통과로 처리하지 않는다.

## 금지 행동

- 원본 기준 문서 수정
- 편집 범위 밖 산출물 변경
- 기존 Figma 페이지 덮어쓰기
- 개발자에게 실제 전달

승인 대상은 현재 산출물 버전으로 한정한다. 승인 후 변경되면 재검사·재승인을 요구한다.

## 출처

실행 정책은 AI가 제안하고 사용자가 채택한 기본값이다.
