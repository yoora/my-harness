# R8 — 검증과 리뷰

상태: 사용자 기본값 승인 완료.

## 판정 스크립트 자체 검증

자동 검사 규칙마다 다음 사례를 시험한다.

- 통과 사례 1개 이상
- 위반 사례 1개 이상
- 증거 누락 사례 1개 이상

모든 사례가 예상 결과와 일치해야 사용한다. 사람 검토 항목은 자동 통과시키지 않는다.

## 전체 흐름 검증

| 시나리오 | 확인할 결과 |
|---|---|
| 정상 진행 | 승인 대기에 도달 |
| 게이트 실패 후 복귀 | 올바른 단계로 복귀 |
| 중단 후 재개 | 변경 여부에 따라 재개 또는 재실행 |
| 승인 후 변경 | 기존 승인 무효화 |

## 최종 리뷰

다음 정보를 한 번에 보여준다.

- Figma 화면 5개 링크
- 규칙별 통과·실패·미검사와 증거
- AI가 보완한 기준 목록
- 서비스 금지 조건 검토 항목
- 남은 문제

필수 자동 검사 실패 또는 미검사가 1건 이상이면 최종 사람 검토·승인을 요청하지 않는다. 사람 검토는 최종 승인 지점에서 수행하며, 미완료 상태를 자동 검사 통과와 혼동하지 않는다. 전체 완료에는 사람 검토 완료와 승인이 필요하다.

## 문서화 범위와 최신 변경

R8 당시에는 최종 AGENTS.md 초안을 대화로 검토하고 승인 후 그 파일만 저장하기로 합의했다. 이후 사용자가 R2~R8을 harness 폴더에 각각 Markdown으로 저장하도록 요청하여 이 7개 문서를 저장한다.

AGENTS.md는 아직 저장하지 않는다. 실제 에이전트 실행·스크립트 생성·Figma 제작·검증 실행은 이후 하네스 실행 시 수행한다. 이 문서의 검증 절차는 명세이며 검증을 실행했다는 기록이 아니다.

## 출처

시험 사례 수, 전체 검증 시나리오와 리뷰 형식은 AI가 제안하고 사용자가 채택한 기본값이다.
