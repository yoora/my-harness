# R3 — 파이프라인

상태: 사용자 기본값 승인 완료.

| 단계 | 작업 | 입력 | 출력 |
|---|---|---|---|
| 1 | 레퍼런스 수집·패턴 분석 | 대상 기능·경쟁 서비스·대상 화면 목록 | 레퍼런스·공통 패턴 |
| 2 | 화면 구조 설계 | 분석 결과·대상 화면 목록 | 화면 구조 문서 |
| 3 | 디자인 규칙 정리 | 화면 구조·design.md | 적용 규칙 |
| 4 | Figma 제작 | 화면 구조·적용 규칙 | Figma 화면 5개 |
| 5 | 검토·전달 준비 | 화면·규칙 | 검토 결과·전달 자료 |

서비스 기준은 전 단계의 판정 기준으로 사용한다.

## 실패 복귀

- 수집 부족: 1단계
- 화면 구조 문제: 2단계
- 규칙 미확정·충돌: 3단계
- 화면의 규칙 위반: 4단계

수정한 단계 이후의 산출물을 다시 검증한다.

같은 게이트에서 자동 수정은 최대 2회 허용한다. 이후에도 미통과이면 멈추고 원인·선택지를 보고한다. 사람 판단을 기다리는 상태는 자동 재시도하지 않는다.

## 출처

5단계 분할, 복귀 방식, 수정 2회 제한은 AI가 제안하고 사용자가 채택한 운영 기준이다.
