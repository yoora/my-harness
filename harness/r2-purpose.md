# R2 — 목적

상태: 사용자 기본값 승인 완료.

## 기준

- `../story-service.md`: 서비스 목적과 위반하면 안 되는 조건의 판정 기준
- `../story-work.md`: 실제 작업 흐름
- `../design.md`: 디자인 기준
- 서비스 목적과 실제 작업 순서를 섞지 않는다.

## 실행별 입력

대상 기능, 대상 화면 목록, 참고할 경쟁 서비스는 실행마다 달라진다. 서비스 기준과 디자인 기준은 실행 중 고정한다.

## 사용자와 범위

디자이너가 실행하고 개발자가 결과물을 받는다. 경쟁 서비스 레퍼런스 수집·분석부터 화면 구조 정리, 디자인 규칙 적용, Figma 화면 5개 제작, 검토와 개발 전달 자료 준비까지 수행한다. 실제 전달은 포함하지 않는다.

## 필수 산출물

- Figma 화면 5개
- 화면 목록·구조 문서
- 적용 규칙
- 검토 결과

## 완료 기준

대상 화면 5개와 필수 산출물이 모두 있고, 필수 검사 미통과 0건·미검사 0건, 사람 승인 1건이면 완료한다. 세부 검사와 승인 위치는 R5를 따른다.

## 출처

실행별 입력 구분, 전달 준비까지의 범위, 산출물 구성, 검사·승인 건수는 AI가 제안하고 사용자가 채택한 기본값이다. 화면 5개는 사용자가 설명한 작업 흐름에 근거한다.
