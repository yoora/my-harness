# R4 — 산출물과 재개

상태: 사용자 기본값 승인 완료. 경로는 이후 승인된 R6의 역할별 폴더 배치를 반영한다.

## 실행 폴더

`runs/<실행ID>/`에 산출물을 모은다. 실행ID는 `YYYYMMDD-HHmmss`이며 같은 이름이 있으면 덮어쓰지 않는다.

| 단계 | 실행 폴더 기준 산출물 |
|---|---|
| 1 | research/references.md |
| 2 | structure/screens.md |
| 3 | rules/rules.json |
| 4 | design/figma-map.json 및 Figma 화면 5개 |
| 5 | review.json, handoff/handoff.md |

`figma-map.json`에는 화면 ID·노드 ID·링크를 기록한다.

## 규칙 단일 기준

실행별 `rules/rules.json` 1개를 스크립트가 읽는 규칙의 단일 기준으로 사용한다. `design.md`와 서비스 금지 조건을 검사 가능한 규칙으로 옮긴다.

각 규칙에는 ID·출처·검사 방식·기준값을 기록한다. AI 보완값을 별도로 표시하며 원문과 충돌하면 게이트에서 멈춘다. 디자인 문서 내부 충돌의 해석 순서는 R5를 따른다.

## 재개

`state.json`에 단계 상태·입력 해시·산출물 경로·검사 결과를 기록한다. 입력과 산출물이 그대로인 마지막 통과 단계 다음부터 재개한다. 변경되거나 누락된 단계와 그 이후는 다시 실행한다.

## 출처

파일명, 저장 구조, 재개 방식은 AI가 제안하고 사용자가 채택한 기본값이다. 이 문서는 향후 하네스 실행 시 생성할 산출물의 명세이며, 지금 실행 산출물을 생성했다는 뜻이 아니다.
