# R5 — 게이트 조건

상태: 사용자 기본값 승인 완료.

## G1 — 레퍼런스 수집 충분성

다음 조건을 모두 만족해야 통과한다.

- 경쟁 서비스 3개 이상
- 레퍼런스 6개 이상
- 각 레퍼런스에 출처·관찰 내용·대상 화면 ID 존재
- 공통 패턴 3개 이상
- 각 공통 패턴이 서로 다른 서비스 2개 이상에서 확인됨
- 대상 화면 5개 모두에 관련 레퍼런스 존재

## G2 — 디자인 규칙 확정

- rules.json의 필수 규칙에 ID·출처·검사 방식·기준값 누락 0건
- 미해결 충돌 0건
- 색·간격·타이포·모서리·그림자·화면 크기 규칙 포함

`design.md` 내부 충돌은 다음 순서로 해석한다.

1. 구체적인 컴포넌트 규칙
2. Do/Don't
3. 일반 설명
4. 예시

같은 우선순위에서 충돌하면 멈춘다.

## G3 — 최종 화면·서비스 조건 검사

- 대상 화면 5개
- 기준 프레임 390×844
- 폭 360px에서 의도하지 않은 가로 넘침 0건
- 적용 규칙 위반 0건

서비스 금지 조건을 다음과 같이 검사한다.

- 자산 공개 범위 기본값은 `private`
- 명시적 사용자 선택 없이 공개·판매 신청으로 바뀌는 전이 0건
- 검수 승인 없이 판매 가능한 전이 0건

관련 화면·상태 명세가 없거나 검증할 증거가 없으면 통과시키지 않는다. 서비스 조건은 설계된 화면·상태 명세 범위에서 검증하며 실제 앱 동작까지 검증했다고 간주하지 않는다.

## H1 — 사람 승인 한 곳

최종 기계 검사 후, 개발 전달 준비 완료 직전에 승인 1회를 둔다.

사람은 디자인 품질과 개인정보·고객정보·회사기밀·타인 저작물 포함 여부를 검토한다. 기계 검사는 탐지 가능한 항목만 보조한다. 사람 검토 미완료 시 작업을 완료 처리하지 않는다.

승인 대상은 현재 산출물 버전이다. 승인 후 결과가 바뀌면 승인은 무효이며 재검사·재승인이 필요하다.

## 출처

디자인 값은 design.md, 서비스 금지 조건은 story-service.md와 PRD에 근거한다. 수집 수치, 검사 방식, 충돌 우선순위, 사람 승인 위치와 복귀 정책은 AI가 제안하고 사용자가 채택했다.
