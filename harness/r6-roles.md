# R6 — 역할과 작업 경계

상태: 사용자 기본값 승인 완료.

## 작업 에이전트

에이전트는 다음 순서대로 실행한다. 폴더는 현재 실행 폴더를 기준으로 한다.

| 역할 | 업무 | 편집 가능한 폴더 |
|---|---|---|
| 리서처 | 수집·패턴 분석 | research/ |
| 설계자 | 화면 구조 | structure/ |
| 규칙 담당자 | 규칙 정리 | rules/ |
| 디자이너 | Figma 제작 | design/ |
| 전달 담당자 | 검토 결과를 바탕으로 전달 자료 정리 | handoff/ |

각 작업 에이전트는 지정된 폴더 1개만 편집한다. 다른 단계 산출물과 원본 기준 문서는 읽기 전용이다. R4 파일명을 유지한다.

디자이너만 지정된 Figma 파일의 이번 실행 전용 페이지를 편집한다.

## 판정과 상태 관리

- 판정자는 산출물·규칙을 읽고 판정만 반환하며 수정하지 않는다.
- 오케스트레이터는 판정을 실행 폴더의 review.json에 기록하고 state.json을 관리한다.
- 전달 담당자는 handoff.md만 작성하며 판정 결과를 바꿀 수 없다.

## 자연어 트리거

| 트리거 | 동작 |
|---|---|
| 디자인 작업 시작 | 입력 확인 후 새 실행 |
| 이어서 진행 | 현재 실행의 상태를 검증하고 재개 |
| 상태 알려줘 | 진행 상황만 보고 |
| 최종 승인 | 최종 승인 대기 중인 현재 결과에만 승인 기록 |

실행 후보가 여러 개면 실행ID를 확인한다.

## 출처

역할, 폴더, 트리거와 판정자·오케스트레이터의 책임 구분은 AI가 제안하고 사용자가 채택한 기본값이다.
